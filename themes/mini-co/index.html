Questions

Do I need to know how to code?

Basic HTML is enough. Products, prices and contact details are edited in one data file, and the documentation shows where everything is.

Can I take real payments with it?

The cart and checkout work in the browser, but the template doesn't take payments on its own. The documentation explains where to connect your payment provider or order service.

Can I use only one language, or change the currency?

Yes. You can delete the French folder to keep only English, and change the currency and price format in the data file.

Which browsers are supported?

Recent versions of Chrome, Edge, Firefox and Safari, on desktop and mobile.

Where can I host it?

Anywhere that serves static files: shared hosting, Netlify, Cloudflare, GitHub Pages or Vercel.
